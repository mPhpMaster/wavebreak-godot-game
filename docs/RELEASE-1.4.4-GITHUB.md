## Changes

- All scoreboard statistics appear together, without a view dropdown.
- Tab opens only the scoreboard; Escape takes priority for pause, including older overlapping saved bindings.
- Equipment hover targets survive character-sheet refreshes. Descriptions show current weapon/tome levels and item-stack effects.
- Cave sharks and Reef Leviathans are restricted to underwater maps across director, scripted, boss, shrine and multiplayer puppet spawn paths.
- Updated English and Arabic What's New entries. Classic Play starts in Thornmeadow.
