## What's new

- Redesigned expedition cards with clearer previews, shorter descriptions and simpler controls.
- Reef and City expeditions open character selection before starting the run.
- Classic Play starts in Thornmeadow, including after a previous expedition selection.
- What's New appears once per installed version and can be reopened from the main menu. Includes Arabic support.
- Flick's Stormfang Blades replace the trailing kite with twin returning blades, three-dimensional targeting and damage while stationary or moving. Existing saves retain their weapon progression.

## Downloads

- `Wavebreak-Setup-1.4.2.exe`: Windows installer.
- `Wavebreak-1.4.2-windows.zip`: portable Windows build.
- `SHA256SUMS.txt`: download checksums.

The existing in-game updater can discover this release. Broader expedition gameplay and art changes remain in development.
